## Regenerating

Ask Cursor to regenerate any diagram using an AI image prompt. Style reference: numbered column pipeline, icons, green/red decision paths, foundation bar, feedback loop, corporate blue theme.

After replacing images in `images/`, rebuild:

```powershell
.\build.ps1
```
